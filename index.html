Getting started

How to install.

Follow these simple steps to install the AthenasMagic modpack and begin your adventure.

01

Download the modpack

Download the AthenasMagic .zip file from our downloads section. Then find it in your Downloads folder and extract its contents.

The package contains the mod files. Fabric must be installed separately in the next step.

02

Install Fabric

Visit the official Fabric website, download and run the installer. Select Client and choose Minecraft 1.21.1. Then click Install.

Make sure you select the correct Minecraft version.

03

Install the mods

Press Win + R, type %appdata%\.minecraft, and press Enter. Open the mods folder (create it if it doesn't exist) and place the .jar files from the extracted package inside it.

Do not place the entire ZIP file inside the mods folder.

04

Launch Minecraft

Open the Minecraft Launcher, select the Fabric Loader 1.21.1 profile, and click Play. Then open Multiplayer and connect to athenasmagic.com.br.

We recommend allocating at least 4 GB of RAM to the game, if your computer has enough memory.

Note: the mods must be compatible with Fabric and Minecraft 1.21.1. If the extracted package already contains a folder named mods, open it and copy the .jar files inside to .minecraft\mods. Minecraft 1.21.1 requires Java 21.
